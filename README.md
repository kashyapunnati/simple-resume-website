# Simple Resume Website

## Project Overview
A single-page resume website created using HTML5 and CSS3 to present my education, skills, projects, and contact information.

## Approach
- Created the webpage structure using HTML5.
- Used CSS3 for layout, spacing, typography, and styling.
- Added a profile photo.
- Organized the resume into clear sections.
- Tested the website and deployed it using GitHub Pages.

## Outcome
The completed website provides a clean and simple online resume that presents my personal and professional information in an easy-to-read format.

## Technologies Used
- HTML5
- CSS3
